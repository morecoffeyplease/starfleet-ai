# Code of Conduct

## Our standard

We welcome people who want to improve Starfleet AI and help others use it.
Treat participants with respect, explain disagreements with evidence, and keep discussion focused on the work.

Unacceptable behavior includes harassment, discriminatory attacks, threats, sexual harassment, disclosure of another person's private information, and deliberate disruption.
Do not publish private conversations or identifying information without permission.

## Reporting a concern

Use the **Community concern** issue form to report a community concern to the project maintainers.
The form automatically applies the `conduct` label.
All issues are public, so do not include private messages, personal information, credentials, or details you are not willing to share publicly.

For abusive content on GitHub, use the content menu and choose **Report content**.
When GitHub offers a choice, **Report to repository admins** sends a report to repository maintainers, while **Report abuse to GitHub Support** goes to GitHub Support for review under GitHub's site rules.
A GitHub Support report is separate from maintainer moderation.
Security vulnerabilities use the private route in [SECURITY.md](SECURITY.md), not this issue form.

## Moderation

Maintainers may edit or remove harmful content, close discussions, restrict participation, or remove contributors when needed to protect the community.
Maintainers consider context and severity and may explain moderation decisions when appropriate.
A maintainer with a conflict of interest should step back when another maintainer is available.
There is no guaranteed response time.
