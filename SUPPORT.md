# Support

Starfleet AI is a source-first community project.
There is no guaranteed response time, release schedule, emergency support service, or paid support plan.

Use GitHub Issues for reproducible bugs, supported setup questions, and feature requests.
Issues are public.
Share the smallest useful redacted evidence, including the component, installed revision, operating system, CMUX build, harness, and relevant CLI versions.

Do not post credentials, webhook URLs, private Discord messages, private review links, complete session transcripts, or unrelated project data.
Use [SECURITY.md](SECURITY.md) to report a suspected vulnerability privately.
The Community concern issue form is also public and should not contain private information.

For message-delivery problems, state whether configuration exists, a request was submitted, and the intended owner actually received the prompt.
Do not claim delivery from a configuration check or fixture result.
